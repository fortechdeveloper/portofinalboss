Halo, saya Yudha Pramudya 👋

Panggil saya FastDev. Saya seorang pelajar di salah satu sekolah di Yogyakarta dan tinggal di Dlingo, Bantul. Ketertarikan saya pada dunia pemrograman mulai dari rasa penasaran: bagaimana caranya sebuah halaman web bisa hidup dan berinteraksi dengan pengguna.

Dari rasa penasaran itu, saya mulai belajar HTML, CSS, JavaScript, lanjut ke C++ untuk logika dan algoritma, hingga Arduino / ESP32 untuk project Internet of Things. Semuanya saya pelajari secara otodidak, dari dokumentasi, forum, dan eksperimen langsung.

Sampai sekarang saya sudah menyelesaikan 58+ project yang sudah live di internet — mulai dari web app, tools kecil, hingga perangkat IoT. Saya percaya bahwa cara terbaik belajar adalah dengan membangun sesuatu dan membagikannya ke publik.
